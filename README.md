# 감성 분석 서비스 프로젝트 지침

이 폴더는 Antigravity AI 코딩 에이전트가 구현할 수 있도록 정리한 프로젝트 지침 문서입니다.

## 문서 구성
- `AGENTS.md`: 에이전트 작업 규칙 및 보안·품질 기준
- `PRD.md`: 제품 목표, 기능 요구사항, 범위, 완료 기준
- `docs/01-project-structure-and-setup.md`: 프로젝트 생성 및 폴더 구조
- `docs/02-ui-design-guide.md`: 첨부 이미지 기반 UI 가이드
- `docs/03-frontend-implementation.md`: HTML/CSS/JS 구현 명세
- `docs/04-backend-api-spec.md`: Node.js API 및 오류 규격
- `docs/05-ai-and-prompt-spec.md`: OpenAI 프롬프트·출력 검증
- `docs/06-testing-deployment.md`: Supabase, 테스트, Vercel 배포

## 에이전트에게 첫 번째로 전달할 요청
`AGENTS.md`, `PRD.md`, `docs/`의 문서를 모두 읽고 요구사항을 요약한 뒤, 구현 계획을 제시하세요. 승인 또는 지시를 받은 범위부터 순서대로 구현하고 각 단계의 검증 결과를 보고하세요.
