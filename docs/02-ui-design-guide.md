# 02. UI 디자인 및 구현 지침

## 1. 참고 이미지에서 가져올 디자인 원칙
첨부된 dcamp 페이지의 **시각적 분위기와 레이아웃 원칙**을 참고한다. 원본 페이지를 그대로 복제하지 않는다.

- 전체 배경: 거의 순수한 검정 `#050505` 또는 `#000000`.
- 기본 글자: 흰색 `#F5F5F5`.
- 보조 글자: 회색 `#A3A3A3`.
- 포인트: 선명한 오렌지 `#FF5A1F` 계열. 로고/작은 강조 요소에 제한적으로 사용.
- 구성: 넓은 여백, 상단에 작은 헤더, 화면 중앙의 매우 큰 굵은 영문 타이포그래피, 얇은 외곽선 글자 장식.
- 분위기: 미니멀, 대담함, 높은 대비, 장식보다 타이포그래피 중심.
- 한국어 본문은 가독성이 높은 산세리프 계열로 표현한다.

## 2. 화면 설계
### 헤더
- 왼쪽: 서비스 텍스트 로고 `moodline` 또는 `moodline.`. 오렌지색.
- 오른쪽: `서비스 소개`, `분석 방법` 같은 화면 내 앵커. 실제 페이지가 하나뿐이므로 동작하지 않는 메뉴 링크는 만들지 않는다.
- 모바일에서는 메뉴를 간소화하고 가로 넘침을 방지한다.

### 히어로
- 큰 메시지 예시: `READ THE FEELING` / `BEHIND YOUR WORDS`.
- 핵심 단어 일부는 흰색 실채움, 반복 장식 문구는 어두운 회색 외곽선으로 표현할 수 있다.
- 외곽선 장식 텍스트는 접근성 트리에서 숨기거나 `aria-hidden="true"`로 지정한다.
- 화면 폭이 좁을 때 글자 크기를 `clamp()`로 줄이고 줄바꿈을 허용한다. 가로 스크롤이 생기면 안 된다.

### 입력 패널
- 히어로 아래에 짧은 한국어 설명을 둔다.
- 넓은 textarea를 제공하고 placeholder는 사용법을 안내한다.
- 입력 글자 수를 표시한다. 서버 제한과 동일한 최대 글자 수를 사용한다.
- 버튼은 오렌지색 배경 또는 흰색 배경 중 하나로 강한 대비를 준다.
- 버튼에 `감성 분석하기`라고 명시한다.

### 결과 패널
- 초기에는 결과 패널을 숨기거나 “문장을 입력하면 결과가 여기에 표시됩니다”라는 안내 상태를 보여준다.
- 결과가 있으면 감정 라벨을 가장 먼저 읽히게 배치한다.
- 긍정/부정/중립은 색상뿐 아니라 텍스트로 표시한다. 예시 색상: 긍정 민트/그린, 부정 코랄/레드, 중립 회색. 다만 전체의 주황 포인트 톤을 해치지 않도록 면적을 작게 쓴다.
- 신뢰도는 `모델 추정 신뢰도 82%`처럼 숫자와 설명을 함께 보여준다. 진행 막대의 `aria-valuenow`, `aria-valuemin`, `aria-valuemax`를 지정한다.
- 분석 이유는 1~3문장 정도의 짧은 텍스트로 보여준다.

### 하단 안내
- “AI 분석 결과는 참고용이며 문맥에 따라 다를 수 있습니다.”
- 사용자가 입력한 문장이 서버에서 분석 및 저장될 수 있다는 점을 짧게 안내한다. 실제 저장 정책은 구현과 일치해야 한다.

## 3. 반응형 기준
- 360px~767px: 모바일 단일 열, 좌우 여백 20px 내외, 큰 타이포그래피 축소.
- 768px~1199px: 태블릿 레이아웃, 콘텐츠 최대 너비 유지.
- 1200px 이상: 넓은 여백과 중앙 정렬, 본문 최대 너비 약 1100~1200px.
- 특정 픽셀 값은 시각적 기준이며 실제 화면에서 조정한다. 단, 360px에서 가로 스크롤이 없어야 한다.

## 4. 인터랙션 상태
- 기본: 입력 가능, 버튼 활성.
- 입력 오류: textarea 또는 입력 아래에 안내.
- 로딩: 버튼 비활성, 스피너 또는 텍스트 `분석 중...`.
- 성공: 결과 카드 표시, 결과 영역으로 포커스 이동 또는 스크린리더 알림.
- 실패: 입력 내용은 보존하고 재시도할 수 있게 오류 표시.
- 재분석: 이전 결과를 새 결과로 교체한다.

## 5. 접근성
- 모든 입력 요소에 label을 연결한다.
- 버튼은 실제 `<button>` 요소를 사용한다.
- 색상 대비를 확인하고 키보드 포커스를 눈에 띄게 표시한다.
- 결과 및 오류 메시지는 `aria-live="polite"` 또는 적절한 alert 영역으로 전달한다.
- 장식용 반복 텍스트는 스크린리더에서 제외한다.
- 애니메이션은 짧고 절제하며 `prefers-reduced-motion`을 지원한다.

## 6. 금지 사항
- 첨부 사이트의 로고, 문구, 메뉴, 브랜드 자산을 그대로 복제하지 않는다.
- 검은 배경 위에 회색 본문을 과도하게 사용해 읽기 어렵게 만들지 않는다.
- 의미 없는 메뉴, 가짜 링크, 작동하지 않는 버튼을 만들지 않는다.
- 결과를 색상만으로 구분하지 않는다.
